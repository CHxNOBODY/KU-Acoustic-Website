# KU Acoustic website redesign

Figma: https://www.figma.com/design/iYOK25aUDu4IHpl1Zku0t0

Branch: `codex/figma-redesign`

## Deliverables

- Editable desktop homepage, 1440 px wide (Figma node `3:2`).
- Editable mobile homepage, 390 px wide (Figma node `3:90`).
- Native text, auto-layout sections, and editable vector vinyl artwork.
- Events: desktop `6:2`, mobile `6:52`; tabs, search, categories, event cards, booking callout.
- Journal: desktop `6:99`, mobile `6:140`; featured story and story cards.
- Gallery: desktop `6:178`, mobile `6:216`; category filters and six club photographs.
- About: desktop `6:255`, mobile `6:306`; community story, values, visit information, FAQ.
- Reduced decorative symbols across the homepage and new pages; text labels replace repeated arrows.
- Club photos uploaded as JPEG assets for reliable Figma preview rendering.

## Direction

Music poster inspired design with forest green (#173E31), warm cream
(#F5F1E8), lime (#D2E87A), and terracotta (#C66C42). Retains the site's
Space Grotesk and Fraunces typography. Uses a vinyl motif as the hero artwork.

Homepage structure: navigation, community hero, events preview, membership
invitation, journal preview, and social/contact footer. Event categories and
story titles are concept content; this file does not change application data.

## Scope

These are Figma concepts for all five public pages, not an implemented website
or interactive prototype. Thai screen variants and admin screens remain future work.
Existing application files and local changes were preserved. No merge or push
to main was performed.
